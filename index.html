📢 Site Announcement / Pop-up

Pop-up Message Settings

Control the message that appears as a pop-up when visitors open your website. Toggle it on or off anytime. The pop-up shows once per browser session.

💡 Tips

  • The pop-up only shows once per browser session — visitors won't see it again until they close and reopen the browser tab.
  • Leave the Promo Code field empty if you have no discount to share.
  • Leave the Button Text and Button Link empty to skip the CTA button.
  • Use the Preview Pop-up button to see how it looks without saving.
